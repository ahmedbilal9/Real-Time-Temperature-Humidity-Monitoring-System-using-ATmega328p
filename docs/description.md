# Project Description

## Abstract
Accurate temperature and humidity monitoring is essential for applications in smart homes, agriculture, and industrial automation.  
This project focuses on developing a **real-time monitoring system** using Embedded C to interface an **SHT/HTU series sensor** with an **ATmega328p microcontroller**.

Unlike typical Arduino-based implementations, this project uses **low-level programming** to directly communicate with the sensor, ensuring better control and efficiency.

---

## Objectives
- Accurate Environmental Sensing → Real-time temperature and humidity measurement with high accuracy.  
- Optimized Low-Level Communication → Embedded C without pre-built Arduino libraries.  
- Data Visualization & Accessibility →  
  - **Web Server Mode:** Remote monitoring using ESP8266 WiFi module.  
  - **OLED Display Mode:** Local monitoring on OLED screen.  
- Scalability & Efficiency → Modular and adaptable for IoT and smart monitoring applications.
